# 🎯 SkillGap AI

SkillGap AI is a Python and Streamlit based Job Skill Gap Analyzer.

## 🚀 Features

- Enter your current skills
- Enter a job description
- Detect required skills
- Calculate skill match percentage
- Identify missing skills
- Generate a learning roadmap
- Store analysis history using SQLite
- View skill dashboard and progress chart

## 🛠️ Technologies Used

- Python
- Streamlit
- SQLite
- Git
- GitHub
